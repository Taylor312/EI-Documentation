# Operator manual

Self-contained instructions for running parts on a station that has already been commissioned and locked into factory mode.

This section assumes an integrator has finished everything in [Setup and integration]({{ site.baseurl }}/setup/): the robot is wired and reachable, the camera job is trained, the routines are taught and loaded, factory mode is switched on, and the unlock password is set. Operators do not need to read the rest of this site.

{: .warning }
The on-screen stop buttons are software stops. They are not a substitute for the hardwired emergency stop on the cell. Know where the physical e-stop is before you run anything.
