## Enable GitHub Pages (one-time)

1. Open the repo on GitHub → **Settings** → **Pages**.
2. Under **Build and deployment** → **Source**, choose **GitHub Actions**.
3. Push to `main` (or re-run the **Deploy Jekyll site to Pages** workflow under the **Actions** tab).

## Local preview (optional)

Requires Ruby + Bundler on your machine:

```powershell
cd "C:\MasterData\Projects\Walter\Easy Inspection Documentation"
bundle install
bundle exec jekyll serve
```

Then open `http://127.0.0.1:4000/EI-Documentation/`.
